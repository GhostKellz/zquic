# Accepted Advisories

No accepted security advisories are currently tracked for `zquic v0.9.16`.

If a vulnerability is knowingly accepted for a release, record:

- advisory identifier
- affected dependency or module
- reason for acceptance
- compensating controls
- target release or condition for removal

The release process should keep this file in sync with `SECURITY.md`,
`CHANGELOG.md`, and any CI advisory ignore list.
